# Opening instruction (before Prompt 1)

First, perform a read-only audit of the repository and produce an implementation plan. Do not install dependencies, change the database, select a paid provider, or write production code yet. Identify the existing stack, product catalog, search capabilities, deployment environment, and testing framework. Clearly separate what can be implemented now from what requires product-data access, credentials, paid services, legal review, medical review, or my approval. End with a recommended Phase 1 implementation and a short list of blocking decisions.
